# keynest

Учебная версия сервиса хранения секретов: **FastAPI + обычные HTML/CSS/JS**.

Без React, npm, сборки и базы данных. Весь бэкенд — один файл `main.py`, весь
фронтенд — три файла в `static/`. Данные хранятся в памяти и исчезают после
перезапуска сервера.

## Запуск

```bash
python -m venv .venv
```

Активировать окружение:

```powershell
# Windows PowerShell
.\.venv\Scripts\Activate.ps1
```

```bash
# Linux / macOS
source .venv/bin/activate
```

Установить зависимости и запустить:

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

Открыть http://127.0.0.1:8000

Документация API: http://127.0.0.1:8000/docs

## Что умеет

- регистрация и вход;
- создание проектов;
- добавление секретов в проект;
- просмотр значений по кнопке «показать»;
- журнал действий: регистрация, вход, создание проекта и секрета, чтение списка.

## API

| Метод | Путь | Что делает |
| --- | --- | --- |
| POST | `/api/register` | создать аккаунт |
| POST | `/api/login` | получить токен |
| POST | `/api/logout` | выйти |
| GET | `/api/me` | проверить токен |
| GET | `/api/projects` | список проектов |
| POST | `/api/projects` | создать проект |
| GET | `/api/secrets` | список секретов |
| POST | `/api/secrets` | добавить секрет |
| GET | `/api/audit` | журнал действий |

Авторизация: заголовок `Authorization: Bearer <токен>`. Токен создаётся при входе
и хранится в памяти сервера.

## Важно

Это учебный код, а не безопасный сервис:

- пароль хешируется SHA-256 без соли — для настоящего проекта нужен Argon2id или bcrypt;
- секреты хранятся открытым текстом — в реальном сервисе нужно шифрование;
- данные в памяти и теряются при перезапуске;
- нет HTTPS, ограничения запросов и нормальной работы с сессиями.

Не вводите сюда настоящие ключи и пароли.

## Идеи для практики

- Добавить удаление секрета и проекта.
- Перейти с памяти на SQLite.
- Заменить SHA-256 на bcrypt.
- Скрывать значение секрета на сервере до отдельного запроса.
- Добавить срок жизни токена.
